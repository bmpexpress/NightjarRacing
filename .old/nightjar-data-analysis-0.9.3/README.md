# Nightjar Data Analysis 0.9.3
GitHub-ready Java 21 / Spring Boot application. Version 0.9.3 adds a hideable sidebar, dark-blue theme, exclusive tack/event switches, corrected sample reporting, revised polar and sail views, including a 0-180 degree half-polar with 0 at the top and 180 at the bottom, variable-axis controls, GPS data bounds and Select only used defaults.

Build: `mvn clean test package`
