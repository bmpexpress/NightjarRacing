### 0.9.2 presentation and plotting revision
- Restored Nightjar branding on the application and password pages.
- Restored the blue interface with orange reserved for selected states and alerts.
- Added Inshore/Offshore event filtering and moved event controls above file inputs.
- Added tack and event colouring to polar, GPS and variable plots.
- Added time averaging with an optional maximum within-bin variable variation.
- Added half, full and Cartesian polar views and corrected half-polar display to 0-180 degrees.
- Added TWS, TWA, BSP and Heel to GPS tooltips.
- Changed continuous plot colours to a blue-to-red scale.
- Moved Save settings to the top of Settings.
- Updated application and download versioning to 0.9.2.
